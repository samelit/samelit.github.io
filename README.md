Инвентаризация 📦

**Сканер штрихкодов для сверки имущества с выгрузкой из 1С**

Работает прямо в браузере телефона: без установки, без сервера, без регистрации.

### **[➡️ Открыть приложение](https://samelit.github.io/inventory.html)**

---

## Зачем это нужно

Загружаете опись из 1С в Excel, выбираете кабинет и сканируете наклейки. Приложение сразу показывает, что с позицией:

| Результат | Что значит |
|---|---|
| 🟢 **Найдено** | Позиция числится в этом кабинете |
| 🟠 **Числится в другом кабинете** | Показывает, где она числится по 1С, и материально ответственное лицо |
| 🔴 **Нет в базе** | Такого инвентарного номера нет в выгрузке |
| 🔵 **Уже отсканировано** | Позиция уже была отсканирована, с указанием кабинета |

Для каждого результата свой звук и своя вибрация, так что сканировать можно и не глядя на экран, например под столом.

## Быстрый старт

1. Откройте **[приложение](https://samelit.github.io/inventory.html)** в Chrome (Android) или Safari (iPhone).
2. Загрузите файл из 1С: Excel (`.xlsx`) или CSV.
3. Выберите кабинет, который инвентаризируете.
4. Нажмите **«Камера»** и наведите штрихкод на рамку. Можно также использовать Bluetooth-сканер или ввести номер вручную.
5. В конце нажмите **«Выгрузить в Excel»**.

## Возможности

- **Формат «Опись имущества».** Файл вида «Опись имущества (Склад … каб. № 101 …)» читается сам: кабинеты, названия, инвентарные номера и МОЛ определяются автоматически. Для любого другого Excel или CSV колонки выбираются вручную.
- **Три способа ввода.** Камера с рамкой-видоискателем и подсветкой (где телефон её поддерживает), Bluetooth-сканер и ручной ввод с цифровой клавиатурой.
- **Учёт по кабинетам.** Счётчики «Найдено», «Осталось», «Чужие» и «Нет в базе» считаются по выбранному кабинету. Переключатель «Показывать все кабинеты» и строка с общим итогом ничего не прячут.
- **Время сканирования.** У каждой позиции в списке стоит время, а для прошлых дней ещё и дата.
- **Стикер с штрихкодом.** Нажмите на позицию, и откроется наклейка с названием, штрихкодом и инвентарным номером. Между позициями можно листать стрелками на экране, свайпом или клавишами со стрелками.
- **Старые наклейки.** Коды вида `6-111` читаются так же: часть после тире игнорируется, и поиск идёт по `6`.
- **Выгрузка в Excel.** В файл попадают все кабинеты, где вы сканировали, включая позиции со статусом «Не найдено». Для каждой строки указаны кабинет и МОЛ по 1С, кабинет, где позицию нашли, и результат.
- **Продолжение работы.** Результаты сохраняются в браузере, поэтому закрытие вкладки их не теряет. Кнопка «Начать заново» сбрасывает сканирование, база остаётся.

## Что нужно для работы

- Телефон с Chrome (Android) или Safari (iPhone) и доступ к камере.
- Страница по HTTPS (она уже размещена на GitHub Pages).
- Интернет при первом открытии, чтобы подгрузились библиотеки для Excel и распознавания штрихкодов.

> 💡 **Если камера не включается**, проверьте разрешение для сайта в настройках браузера. На iPhone: *Настройки → Safari → Камера → Разрешить*.

## Конфиденциальность

Файл из 1С и результаты сканирования обрабатываются только на вашем устройстве и никуда не отправляются. Сервера у приложения нет.
